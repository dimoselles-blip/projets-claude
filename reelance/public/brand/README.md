Déposez ici le logo définitif de Reelance :

- `logo.svg` — version couleur, pour fonds clairs
- `logo-white.svg` — version blanche, pour fonds sombres (pied de page, back office)
- `favicon.svg` — icône carrée (optionnel, remplace `src/app/icon.svg`)

Puis passez `USE_BRAND_FILE` à `true` dans `src/components/brand/Logo.tsx`.
