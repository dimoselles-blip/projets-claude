Fichiers du logo Reelance :

| Fichier | Usage |
| --- | --- |
| `logo.svg` | Logo principal, lettres noires, pour fonds clairs |
| `logo-white.svg` | Lettres blanches, pour fonds sombres (pied de page, back office, visuels noirs) |
| `icon.svg` | Icône « ee » jaune sur carré noir (favicon, application, réseaux sociaux) |
| `mark.svg` | Symbole « ee » seul, sans fond |
| `logo-mono-black.svg` | Tout noir : sur fond jaune, impression une couleur |
| `logo-mono-white.svg` | Tout blanc : sur photo ou fond coloré foncé |
| `logo-email.png` | Version PNG pour les e-mails (les messageries n'affichent pas le SVG) |
| `logo-original.webp` | Fichier fourni, conservé comme référence |

Les SVG ont été vectorisés à partir de `logo-original.webp`. Si le fichier source vectoriel
(AI, EPS, SVG ou PDF) est disponible, remplacez `logo.svg`, `logo-white.svg` et `mark.svg`
par des exports de ce fichier pour une netteté parfaite en grand format (impression, bâches).
